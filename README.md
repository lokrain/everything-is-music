# Everything is Music

This platform exists to make the inner workings of music understandable, accessible, and engaging for anyone who feels drawn to it—regardless of background, ability, or prior experience. It addresses a growing cultural distance from meaningful listening and music-making, offering a path back to active engagement rather than passive consumption.

## Features

- **Interactive Piano Keyboard**: Click keys to play notes and learn the fundamentals of pitch
- **Educational Lessons**: Step-by-step lessons covering music theory basics from beginner to intermediate levels
- **Accessible Design**: Built with accessibility in mind, including keyboard navigation and high contrast
- **Progressive Learning**: Lessons organized by difficulty with clear topics and duration
- **Active Learning Approach**: Emphasizes doing and understanding over passive consumption

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm start
```

## Technology Stack

- **Next.js 16**: React framework with App Router
- **TypeScript**: Type-safe code
- **Tailwind CSS**: Utility-first styling
- **Web Audio API**: Interactive sound generation for the piano keyboard

## Project Structure

- `/app` - Next.js app router pages and layouts
- `/components` - Reusable React components
- `/public` - Static assets
